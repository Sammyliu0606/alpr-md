# License plate cameras in Maryland

A Capital News Service story about automated license plate reader (ALPR) cameras expansion in Maryland.

**Live page:** https://sammyliu0606.github.io/alpr-md/

By Sammy Liu and Jake Tiger.

## Run it locally

From this folder:

```bash
npx serve .
```

Then open the address it prints.

## What's here

- `index.html` — the story page, including the map
- `css/`, `js/`, `icons/` — page styles and scripts
- `images/` — map images exported from Mapbox, one per zoom level
- `shots/` — camera screenshots
